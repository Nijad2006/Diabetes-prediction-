# 🩺 Diabetes Prediction Web App

A simple **Machine Learning-based Diabetes Prediction Web Application** built using **Python, Flask, and Scikit-learn**.

The application takes basic health information from the user and uses a trained machine learning model to predict whether the input indicates **Diabetes**.

## 🚀 Features

* 🩺 Diabetes prediction using a trained ML model
* 🌐 Flask-based web application
* 📊 Accepts four health-related inputs:

  * Age
  * Blood Pressure
  * Blood Sugar
  * BMI
* 🤖 Loads a pre-trained model using Python `pickle`
* ⚡ Provides predictions through a simple web interface
* 🔄 Uses the same feature order as used during model training

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **Scikit-learn**
* **Pickle**
* **HTML/CSS**
* **Machine Learning**

## 🧠 Model Input Features

The application accepts the following four features:

| Feature        | Description                    |
| -------------- | ------------------------------ |
| Age            | Age of the patient             |
| Blood Pressure | Patient's blood pressure value |
| Blood Sugar    | Patient's blood sugar value    |
| BMI            | Body Mass Index                |

The values entered through the web form are converted to floating-point numbers and passed to the trained model in the same order used during training.

## ⚙️ How It Works

The Flask application loads the trained machine learning model from:

```python
diabetes_model.pkl
```

When the user submits the form, the application collects:

```text
Age
Blood Pressure
Blood Sugar
BMI
```

These values are arranged into a feature array and passed to the trained model:

```python
prediction = model.predict(features)
```

The prediction is then displayed on the webpage in the format:

```text
Diabetes: <prediction>
```

The Flask application contains two main routes:

* `/` → Displays the prediction page
* `/predict` → Processes the submitted health information and generates the prediction

## 💻 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/diabetes-prediction.git
```

### 2. Navigate to the Project Folder

```bash
cd diabetes-prediction
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
.venv\Scripts\activate
```

**Linux/macOS:**

```bash
source .venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install flask scikit-learn
```

## ▶️ Run the Application

Start the Flask server:

```bash
python app.py
```

You should see Flask start the development server.

Open the application in your browser:

```text
http://127.0.0.1:5000/
```

## 🔮 Making a Prediction

1. Open the web application.
2. Enter the patient's:

   * Age
   * Blood Pressure
   * Blood Sugar
   * BMI
3. Click the prediction/submit button.
4. The application displays the model's diabetes prediction.
